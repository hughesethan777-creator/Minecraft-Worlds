# Minecraft Worlds

Both worlds below share the same castle layout: a moat with a causeway
bridge, a twin-tower gatehouse, four crenellated corner towers, connecting
curtain walls with arrow slits, a paved courtyard, and a tall central keep
with glass windows, two internal floors, and a stepped roof.

## Castle World (Java Edition)

A Java Edition (Anvil format) world save.

### How to play it

1. Copy the `CastleWorld/` folder into your Minecraft `saves` directory:
   - Windows: `%appdata%\.minecraft\saves\`
   - macOS: `~/Library/Application Support/minecraft/saves/`
   - Linux: `~/.minecraft/saves/`
2. Launch Minecraft Java Edition and select **Castle World** from the
   world list. The client will silently upgrade the old world format on
   first load — that's expected.
3. You'll spawn in creative mode on the bridge, facing the gate.

Generated by `scripts/build_castle.py` using
[`anvil-parser2`](https://pypi.org/project/anvil-parser2/) — raw `.mca`
region files plus a hand-built `level.dat`, no running Minecraft instance
required.

## Castle World Bedrock (Bedrock Edition)

A Bedrock Edition (LevelDB format) world, built from the same layout.

### How to play it

- **Easiest:** send `CastleWorldBedrock.mcworld` to your device and open it
  (or double-click it on desktop) — Minecraft will import it directly into
  your worlds list.
- **Manually:** copy the `CastleWorldBedrock/` folder into
  `com.mojang/minecraftWorlds/` (on Windows:
  `%localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\minecraftWorlds\`).
- You'll spawn in creative mode on the bridge, facing the gate.

Generated by `scripts/build_castle_bedrock.py` using
[`amulet-core`](https://pypi.org/project/amulet-core/) /
[`amulet-leveldb`](https://pypi.org/project/amulet-leveldb/), which writes a
real LevelDB database plus `level.dat`/`levelname.txt`. Blocks are described
using Java Edition identifiers and translated to Bedrock automatically via
PyMCTranslate, so both scripts share the same block names.

### Regenerating / customizing either world

```
pip install -r scripts/requirements.txt
python3 scripts/build_castle.py CastleWorld                  # Java
python3 scripts/build_castle_bedrock.py CastleWorldBedrock   # Bedrock
```

Edit the constants and the `build()` function in either script to change
the castle's size, position, or add more detail — the two scripts use
matching helper functions (`fill`, `setb`, `tower`, `hollow_box`) so changes
are easy to port between them.
